# Gemini MCP 视觉与流畅度红队复核

- 日期：2026-08-30
- 调用：`mcp__gemini__ask_gemini`
- 模式：High effort
- 目标：检查《纹生万象》的高级感、当代东方气质、结果海报独立性与移动端流畅度

## Gemini 重点风险

1. 大面积依赖系统楷体可能在不同设备降级为景区/政务式视觉。
2. 细框、圆环、英文、印章若全部堆叠，会落入模板化“国潮拼盘”。
3. 圆角卡片与模糊阴影过多，会像套国风皮肤的 SaaS 工具。
4. Canvas 纯矢量需要纸张颗粒与矿物色调，避免 Flash 式塑料感。
5. 结果海报需要 38%–48% 留白、严谨元数据与非中心化视觉张力。
6. 多圆形硬边 Clip 容易显得机械，应改成羽化的墨晕揭示。

## 已落实

- 展示字体改为宋体/明体优先字体栈，印章保留书法感。
- 全局圆角收紧至 4–8px，普通卡片移除模糊投影，仅结果海报保留层级。
- 海报加入程序化纸张颗粒、矿物低饱和色阶、偏轴元数据、双层 hairline、斑驳朱砂印章。
- 镜像构图减少重复单元，增加中央主纹样与 40% 左右留白。
- 生成动画由硬边圆形 Clip 改为离屏 Mask + Radial Gradient 的水墨羽化揭示。
- 手绘改为逐段增量绘制；控制项渲染使用 requestAnimationFrame 合帧。
- Tab、按钮、选项、Toast、滚动显现统一使用 `cubic-bezier(.16,1,.3,1)` 一类减速曲线。

## 最终量化复核

- 390px：`scrollWidth === clientWidth === 390`
- 375px：`scrollWidth === clientWidth === 375`
- 320px：`scrollWidth === clientWidth === 320`
- 生成动画：0 个 Long Task（阈值 50ms）
- 控制台：0 error / 0 warning
- 海报导出：900×1200，Alpha 全不透明
- 无缝 Tile：960×960；左右、上下边缘差异均为空
