# 纹生万象 V2 · 中式生成艺术工坊

> **一笔成纹，把你的手势织进千年。**  
> 画的不只是纹样，也是生成纹样的方法。

《纹生万象》V2 是一款移动端优先、完全离线运行的生成艺术小工具。用户第一次打开只需要做一件事：**画一笔**。松手后，笔迹会自动平滑、归一化并立即生长成完整纹样；随后才逐层开放纹元、纹法、色谱、工坊与 Remix。

V2 不再通过增加固定题库或大量预置素材扩展内容，而是把内容生产权交给用户：用户可以创建自己的笔势、纹元、纹法和色谱，并把这些规则编码为自包含的 **万象码（WX2）**。其他用户无需服务器即可导入、复现和 Remix。

## V2 核心变化

- 删除固定三关“古纹修复”及其独立 Canvas / 计分状态。
- 一级导航收敛为：**造纹 / 工坊 / 纹谱**。
- 删除“先选参数再点生成”的必经流程；改为 **PointerUp 松手即生纹**。
- 首次完整生长动画约 0.56 秒；后续参数修改直接重绘，不重复长动画。
- 保留 5 个经典纹元作为新手托底：云雷、缠枝、莲瓣、团花、如意。
- 保留 5 个经典纹法作为即点即用模板；用户也可创建自己的规则组合。
- 支持创建自定义纹元（最多两笔，保存时量化）、自定义纹法、自定义色谱。
- 支持“灵光”快速变体：保留当前笔势，快速重新组合纹元 / 纹法 / 色谱。
- “传纹”从一级页面变成作品动作：作品完成后直接分享、发起挑战或分享组件。
- 本地工坊只保存规则与万象码，不保存 Base64 大图；缩略图按需重绘。
- 收藏作品进入本地纹谱，可继续 Remix 或复制万象码。

| 指标 | 目标 |
|---|---:|
| 首屏理解 | ≤ 3 秒 |

设计原则是：**先让用户觉得好玩，再让用户发现它很深。**

## 万象工坊

内容模型只有四种组件：

```text
Stroke 笔势
  ×
Motif 纹元
  ×
Rule 纹法
  ×
Palette 色谱
  =
Composition 作品
```

### 笔势 Stroke

决定纹样往哪里生长。原始 Pointer 数据只存在内存，最终会压缩为最多 16 个量化控制点；恢复时重新平滑和重采样。

### 纹元 Motif

决定“长的是什么”。经典纹元由项目内置绘制器负责；用户纹元由通用矢量点绘制器负责，二者共用同一套 Rule Engine。

### 纹法 Rule

纹法不是任意 JavaScript，而是一组受限、可验证、可编码的生成参数：

- 排列：沿势 / 镜生 / 横生 / 纵生 / 四方 / 环生
- 对称：无 / 左右 / 上下 / 四向
- 重复：2–12
- 旋转：不转 / 微旋 / 斜转 / 随势 / 交替
- 交错：整齐 / 错半格 / 隔格翻转 / 大小交替
- 生长：均匀 / 渐大 / 渐小 / 呼吸

用户无法通过 Seed 注入脚本；Decoder 会对长度、枚举与数值范围进行限制。

### 色谱 Palette

只保存 4 个核心颜色：纸色、主色、辅色、点色。万象码使用 RGB444 量化保存，减少传播长度。

## 万象码 WX2

V2 使用组件化 Seed：

```text
WX2-S-...   笔势
WX2-M-...   纹元
WX2-R-...   纹法
WX2-P-...   色谱
WX2-C-...   完整作品
WX2-H-...   挑战
```

编码特点：

- Base64URL，无 padding；
- 自包含，不依赖服务器和数据库；
- CRC16-CCITT 检查剪贴板损坏；
- 完整作品携带直接父级 fingerprint，支持轻量“纹脉” Remix；
- 不携带完整祖先链，避免每次 Remix 让 Seed 变长；
- 兼容旧版 `WW-...` Seed，导入时会转换为 V2 作品。

### 同笔不同纹

挑战码 `WX2-H` 可以锁定笔势，让另一位用户只修改纹元、纹法和色谱。整个过程不需要实时联网：

```text
A 画一笔
→ 分享挑战码
→ B 导入
→ 复现同一笔势
→ B Remix
→ 生成新的纹脉
```

小红书笔记本身可以承担作品发现、Seed 传播和评论互动，因此小工具内部不伪造在线人数、点赞榜或假社区。

## 渲染结构

V2 将实时渲染划分为三层概念：

```text
StrokeModel
    ↓
RenderPlan
    ↓
Paint
```

当前实现会缓存笔势重采样模型和规则生成计划：

- 重画笔势：重新计算 StrokeModel + RenderPlan；
- 更换纹元 / 纹法：使 RenderPlan 失效；
- 更换色谱：沿用几何计划，只重绘；
- 所有普通实时更新由 `requestAnimationFrame` 合并。

实时 Preview 根据容器宽度控制在约 420–540 px 宽；只有用户导出时才临时创建 900×1200 高分辨率 Canvas，导出后立即释放 backing store。

## 隐私与离线

- 笔势、组件、纹谱默认留在当前浏览器。
- 不采集账号、位置、通讯录、设备标识。
- 没有埋点和网络同步。
- 删除本地纹谱不会让已经分享出去的万象码失效，因为 Seed 是自包含的。

## V2 设计判断

《纹生万象》不再通过“加入更多东西”变强。

它通过：

> **让用户成为内容作者。**

程序只需要保持一套足够快的 Canvas 引擎、一套受限但有表现力的规则、一套可验证的 Seed Codec 和一条很短的 Remix 路径；之后无限的笔势、纹元、纹法、色谱和作品都可以来自用户，而不是继续塞进生产包。
