# 纹生万象 · 中式纹样生成实验室

> 一笔成纹，把你的手势织进千年。

《纹生万象》是一款移动端优先、完全本地运行的中式纹样生成小工具。用户画下一笔，程序将笔迹压缩为可复现的“纹样 DNA”，再按镜像、旋转、二方连续、四方连续或放射团花等结构生成纹样。

它不是随机图片生成器。手势、纹样体系、结构算法、配色、密度与节奏都会进入结果和 Seed；同一 Seed 可在另一台设备上恢复同一基础作品，再继续修改，形成“传纹”异步接力。

## 功能清单

- Canvas 2D 手绘输入，支持鼠标、触屏与 Pointer Events
- 手势骨架生成：Chaikin 平滑、弧长重采样、切法线与曲率派生
- 5 个纹样体系：云雷、缠枝莲、莲瓣、团花、如意云
- 5 种结构：镜像、旋转、二方连续、四方连续、放射团花
- 5 套配色：朱砂、石青、黛青、松烟、月白
- 一笔成纹生长动画，可调密度与节奏
- 32 字符自包含 Seed：编码笔迹采样点与全部生成参数
- “传纹”异步接力：复制 Seed → 朋友输入 → 恢复同一基础作品
- 三关古纹修复小游戏：观察连续规律，补回缺失单元
- 本地纹谱：收藏、历史、恢复、移除；数据仅保存在浏览器 localStorage
- 导出 3:4 小红书卡片、9:16 壁纸、1:1 方图、960×960 无缝 Tile
- PNG 保存；无缝 Tile 的上下、左右边缘像素已闭合
- 检测 `window.xhs.miniTool`：支持时调用发笔记/保存能力，不支持时复制文案并本地保存
- 320 / 375 / 390px 移动端无横向溢出
- 零框架、零后端、零外部 API、零 CDN、零远程字体

## 本地运行

直接双击 `index.html` 即可体验主要功能。为获得与小工具容器更接近的运行环境，建议启动任意静态文件服务：

```powershell
python -m http.server 8787 --directory .
```

然后访问 `http://127.0.0.1:8787/`。

## Seed 设计

Seed 使用 32 字符的大写 Base32 短码，自包含以下信息：

1. 版本位；
2. 纹样体系、结构算法、配色；
3. 密度与生长节奏；
4. 最多 11 个量化笔迹采样点；
5. 双字符校验码。

Seed 不依赖服务器或数据库。恢复时会先校验格式与校验码，再还原参数和笔迹。因此它可以跨设备复制，也不会因为清除本机历史而失效。

## 生成算法

主作品使用“手势骨架生长”而非坐标阵列盖印：

1. 将用户笔迹平滑并等距重采样为 72 个骨架点；
2. 计算每一点的切线、法线、曲率和相对主弦偏移；
3. 将同一条骨架映射为镜像、旋转、二方连续、四方连续或放射结构；
4. 云雷沿骨架形成连续回纹带，缠枝莲沿切线萌发枝叶，莲瓣与团花使用法向包络，如意云在骨架端点生成云头；
5. 动画按照骨架弧长逐段揭示，因此画面变化与用户的一笔直接相关。

## 导出规格

| 选项 | 像素 | 用途 |
|---|---:|---|
| 3:4 小红书卡片 | 900×1200 | 参赛笔记主图、封面 |
| 9:16 壁纸 | 900×1600 | 手机壁纸、竖屏展示 |
| 1:1 方图 | 1080×1080 | 头像、方形社交图 |
| 无缝 Tile | 960×960 | 连续纹样铺陈、包装与背景演示 |

无缝 Tile 会使用周期性边缘单元，并在导出末尾闭合首尾像素。QA 中已验证左右、上下边缘像素差异为空。

## 小红书容器适配

运行时会检测：

```js
window.xhs?.miniTool
```

- 存在 `publishNote`：提交标题、文案与 PNG Data URL；
- 存在 `saveImage`：提交图片 Data URL 与文件名；
- 未提供容器能力或调用失败：保留本地 PNG 下载，并复制 Seed 投稿文案。

容器接口名称若与最终 Builder Hub 文档不同，只需在 `sharePattern()` 内替换适配层，不影响其他功能。
